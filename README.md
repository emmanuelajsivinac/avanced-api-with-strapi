<h1 align="center">Advanced API with Strapi CMS and Node.js</h1>

This project is a **generic boilerplate API** built with **Strapi CMS** and **Node.js**.  
It serves as a flexible foundation that you can extend, customize, and adapt to your own needs.  

By default, it includes:

1. User authentication (sign in)  
2. Basic user role management  
3. Product listing retrieval  
4. Product search functionality  
5. Add items to the cart  
6. Upload and manage inventory
